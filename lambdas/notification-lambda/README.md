# Notification Lambda (inactive example)

This source handles TrackingStatusUpdated messages and sends email through SES, using Node.js and AWS SDK v3. It is preserved as an extension example.

There is no active notification live stack, SQS event-source mapping, SES provisioning or bootstrap integration. The current platform does not deploy or verify this component. Do not include it in active architecture or delivery claims. See the [implemented event path](../../docs/architecture/current-platform.md#event-path).
