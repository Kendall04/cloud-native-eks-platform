# Reporting security concerns

This is a portfolio demonstration, not a continuously operated or supported production service. The AWS runtime was retired; the public DEMO uses synthetic data. No response or remediation SLA is promised.

Do not include credentials, tokens, private keys, Terraform state, personal data or exploit payloads in public issues, comments or attachments. Report the affected source revision and component without exposing sensitive material.

GitHub private vulnerability reporting was not enabled when checked on 3 November 2026. Do not assume a private advisory submission is available. Contact the [maintainer](https://github.com/Kendall04) through a contact method they publicly provide; if none is available, open an issue asking for a private reporting channel **without vulnerability details** and wait for an agreed channel before sharing them. No email address or continuous monitoring commitment is implied.

For implemented boundaries, retained findings and evidence limits, see [security documentation](docs/security.md). Scanner results and documented exceptions are not a guarantee that the project is vulnerability-free.
